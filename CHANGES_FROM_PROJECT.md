# Changes from the working project

## What this repository is a snapshot of

This repository is a snapshot of the author's working KG-COST project, taken on 2026-10-19. It was built by copying an explicit allow-list of 110 files (pipeline source code, tests and test fixtures, the Neo4j load files, three gold tables, and two documentation files) from the working project, then scrubbing machine-specific paths, a personal contact address, an unpublished study name and local Neo4j identifiers from 16 of them. The other 94 copied files are byte-identical to the working project. Files added only for this release (README, LICENSE, NOTICE, CITATION.cff, .zenodo.json, .gitignore, data/README.md, src/grouper/jars/README.md, this file, MANIFEST.sha256) are not part of the working project. The working project's development history is not included. `RUNBOOK.md` is kept as the author's working log; it refers to some working documents (for example `CLAUDE.md` and planning files) that are not part of this snapshot.

## Not shipped

- Patient-level NTDB-annotated rows and any other NTDB-derived data (the working project's `data/derived`). The NTDB is restricted data and cannot be redistributed. A 100-row synthetic NTDB-shaped fixture (`tests/fixtures/ntdb_synthetic_100.parquet`, produced by `tests/_build_ntdb_synthetic.py`) is shipped instead.
- Bronze and silver intermediate data (`data/bronze`, `data/silver`): downloaded CMS files and intermediate tables produced by the code in `src/extract` and `src/transform`. Only the three gold tables in `data/gold` are shipped.
- Neo4j bulk-import files (`data/neo4j_import`): generated by `src/load/build_csvs.py`.
- Logs, scratch files, plans, archived documents and other development material (`logs/`, `scratch/`, `plans/`, `docs/archive/`, `background/`, `tools/`): working material from development, not needed to run the pipeline.
- The CMS MS-DRG grouper JARs, any other vendored JARs (`vendor/`), and the compiled driver classes (`src/grouper/driver/_classes/`): the JARs are third-party software that is not redistributed here (see `src/grouper/jars/README.md`); the compiled classes are rebuilt from the shipped `KGCostGrouperDriver.java`.
- The empty Neo4j placeholder files `neo4j/data/.gitkeep`, `neo4j/logs/.gitkeep` and `neo4j/plugins/.gitkeep` (zero-byte files that only keep otherwise empty folders in the working project). Only `neo4j/docker-compose.yml` and `neo4j/conf/neo4j.conf` are shipped from that folder.
- The working project's own `README.md` and `.gitignore`. Both are replaced here by new files written for this release.
- The local `.env` file, the author's local tooling instructions (`CLAUDE.md`, `.claude/`), Word documents, and caches (`__pycache__`, `.pytest_cache`, `.DS_Store`).

The changes are limited to removing private defaults and identifiers, requiring formerly defaulted paths (an unset NTDB DuckDB path now raises an error), renaming default output files, correcting package metadata and two dependency pins (`drgpy`, `pandas`) together with the removal of the `setuptools` cap that only the old `drgpy` pin needed, replacing one test assertion and adding three tests; no cost lookup, grouping or routing logic was changed.
